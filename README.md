# ⚽ Preguntas de Fútbol

Juego de preguntas de fútbol para 2 jugadores, estilo tablero (x100 a x500).

**Jugar online:** https://m4rt1n1309.github.io/preguntas-futbol/

## Reglas
- En cada partida se sortean las categorías (4, 5 o 6) entre 12 disponibles.
- En cada columna se empieza por abajo (x100) y se va subiendo.
- Los jugadores se turnan para elegir; si aciertan suman los puntos de la casilla.
- Opcional: rebote (si uno falla responde el rival), restar puntos al fallar y tiempo límite.

## Agregar preguntas
Editar `preguntas.js`. La **primera opción** de cada pregunta es la correcta (el juego las mezcla al mostrarlas).
